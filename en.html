Overview

Project Overview

This project is a data visualization template for observing repricing flows. It is designed to show when prices moved, how large the changes were, and how each movement shaped the final result.

The original academic project structure is preserved, while the main screen now includes scroll-based transitions and a corporate-style top navigation with separated language links.

Method

Analysis Flow

Price history is divided into a baseline, change intervals, and final outcome. Each interval becomes a small explanatory unit that connects a cause to its visible effect.
